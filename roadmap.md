# Project Roadmap

This document outlines the long-term vision and planned development milestones for the GitHub Project Dashboard.

---

## ✅ Version 1.0: Core Functionality (Completed)

-   **Authentication**: Secure login using GitHub Personal Access Token (PAT).
-   **Data Fetching**: Fetch all user repositories, including private ones.
-   **Dashboard View**:
    -   Summary statistics (total, public, private repos).
    -   Top language breakdown.
    -   Responsive grid of repository cards.
-   **Detail View**:
    -   Display detailed info for a selected repository.
    -   Fetch the latest commit.
    -   AI-powered analysis of the commit source.
-   **Core UI**:
    -   Sidebar with a sorted list of projects.
    -   Header with user info, refresh, and sign-out controls.
-   **Search & Filter**: Search by name, filter by public/private status. ✅ (2026-03-08)
-   **Commit History**: Show last 10 commits. ✅ (2026-03-08)
-   **Error Handling**: Detailed error messages for API errors. ✅ (2026-03-08)

---

## 🎯 Version 1.1: Enhanced Interactivity & Visualization

-   **Goal**: Make the dashboard more interactive and provide richer data insights.
-   **Key Features**:
    -   Implement comprehensive search and filtering for repositories.
    -   Integrate interactive charts for language statistics.
    -   Develop a multi-commit history view within the detail panel.
    -   Improve UI feedback with enhanced loading states and animations.

---

## 🚀 Version 1.2: Customization & Deeper Integration

-   **Goal**: Allow users to personalize their experience and integrate more GitHub features.
-   **Key Features**:
    -   Add a settings panel for user preferences (e.g., theme toggle, grid density).
    -   Integrate with GitHub Organizations to view organization repositories.
    -   Display basic Issue and Pull Request information on the repository detail page.
    -   Explore GitHub OAuth as an alternative, more user-friendly authentication method.

---

## 🌌 Future Vision: Advanced Analysis & Collaboration

-   **Goal**: Transform the dashboard into a powerful productivity tool.
-   **Potential Ideas**:
    -   Use Gemini for deeper code analysis: Summarize recent code changes, identify potential issues, or suggest documentation.
    -   CI/CD pipeline status indicators on repository cards.
    -   Ability to favorite or categorize projects within the dashboard.

---

# 專案藍圖

本文件概述了 GitHub 專案儀表板的長期願景和計劃的開發里程碑。

---

## ✅ 版本 1.0: 核心功能 (已完成)

-   **身份驗證**: 使用 GitHub 個人存取權杖 (PAT) 進行安全登入。
-   **數據抓取**: 抓取所有使用者專案，包含私有專案。
-   **儀表板視圖**:
    -   摘要統計（總數、公開、私有專案）。
    -   最常使用的程式語言分析。
    -   響應式的專案卡片網格。
-   **詳細視圖**:
    -   顯示所選專案的詳細資訊。
    -   抓取最新的提交紀錄。
    -   由 AI 驅動的提交來源分析。
-   **核心介面**:
    -   帶有已排序專案列表的側邊欄。
    -   包含使用者資訊、刷新和登出控制項的頁首。

---

## 🎯 版本 1.1: 增強互動性與可視化

-   **目標**: 使儀表板更具互動性，並提供更豐富的數據洞察。
-   **主要功能**:
    -   實作全面的專案搜尋與篩選功能。
    -   整合互動式圖表以顯示語言統計數據。
    -   在詳細資訊面板中開發一個可查看多筆提交歷史的視圖。
    -   透過優化的載入狀態和動畫來改善 UI 反饋。

---

## 🚀 版本 1.2: 客製化與深度整合

-   **目標**: 允許使用者個性化其體驗，並整合更多 GitHub 功能。
-   **主要功能**:
    -   新增一個設定面板，用於使用者偏好設定（例如：主題切換、網格密度）。
    -   整合 GitHub Organizations 功能，以查看組織的專案。
    -   在專案詳細頁面上顯示基本的 Issue 和 Pull Request 資訊。
    -   探索使用 GitHub OAuth 作為更友好的替代驗證方法。

---

## 🌌 未來願景: 進階分析與協作

-   **目標**: 將儀表板轉變為強大的生產力工具。
-   **潛在構想**:
    -   使用 Gemini 進行更深入的程式碼分析：總結最近的程式碼變更、識別潛在問題或建議文件。
    -   在專案卡片上顯示 CI/CD 流程的狀態指示器。
    -   在儀表板內對專案進行收藏或分類的功能。
